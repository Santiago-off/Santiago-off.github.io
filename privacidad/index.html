3. Qué datos tratamos y para qué

3.1 Cuando visitas la web

La web es un sitio estático alojado en GitHub Pages. Para servirte las páginas, GitHub recibe datos técnicos de tu conexión, como tu dirección IP. GitHub indica que registra y guarda la dirección IP de quienes visitan sitios de GitHub Pages con fines de seguridad. Nosotros no tenemos acceso a esos registros. GitHub los trata según su propia declaración de privacidad.

La web no tiene registro de usuarios, formularios de contacto, publicidad ni analítica de terceros.

3.2 Contador de visitas

La web tiene un contador de visitas propio, que solo sirve para saber cuánta gente la visita de forma agregada. Funciona sin cookies y no guarda ni lee nada en tu dispositivo.

De cada visitante guarda:

  • Un hash irreversible de la dirección IP (HMAC-SHA256 con una clave secreta). La dirección IP nunca se guarda. No podemos convertir el hash de nuevo en una dirección IP. En las direcciones IPv6 solo se usa el prefijo de red (/64), no la dirección completa.
  • La fecha de la primera visita y la de la última.
  • El número de visitas.
  • El país, como código de dos letras (por ejemplo, «ES»).

Además guarda totales diarios (cuántas visitas y cuántos visitantes nuevos hubo cada día), que no identifican a nadie.

El contador funciona en Cloudflare Workers y guarda sus datos en una base de datos de Cloudflare. Cloudflare necesita ver tu dirección IP un instante para responder a la petición, y es quien aporta el código de país.

Respeta «Do Not Track» y Global Privacy Control. Si tu navegador envía la señal «Do Not Track» o la de Global Privacy Control, tu visita no se cuenta y no se guarda nada.

Aunque el hash no se puede revertir, lo tratamos como dato personal (dato seudonimizado) y lo protegemos como tal.

4. Qué no hacemos

  • No usamos cookies ni otras técnicas para seguirte por esta web o por otras.
  • No vendemos, alquilamos ni compartimos datos personales con terceros para sus propios fines.
  • No usamos los datos para publicidad, elaboración de perfiles ni decisiones automatizadas (art. 22 RGPD).

3. What data we process and why

3.1 When you visit the website

The website is a static site hosted on GitHub Pages. To deliver the pages, GitHub receives technical data from your connection, such as your IP address. GitHub states that it logs and stores the IP address of visitors to GitHub Pages sites for security purposes. We do not have access to those logs. GitHub handles them under its own privacy statement.

The website has no registration, no contact forms, no advertising and no third-party analytics.

3.2 Visit counter

The website has its own visit counter, used only to know how many people visit the site in aggregate. It works without cookies and does not store or read anything on your device.

For each visitor it keeps:

  • A one-way hash of the IP address (HMAC-SHA256 with a secret key). The IP address itself is never stored. We cannot turn the hash back into an IP address. For IPv6 addresses only the network prefix (/64) is used, not the full address.
  • The date of the first visit and of the last visit.
  • The number of visits.
  • The country, as a two-letter code (for example, "ES").

It also keeps daily totals (how many visits and how many new visitors there were each day), which identify no one.

The counter runs on Cloudflare Workers and stores its data in a Cloudflare database. Cloudflare needs to see your IP address for an instant in order to answer the request, and it provides the country code.

It honours "Do Not Track" and Global Privacy Control. If your browser sends the "Do Not Track" or the Global Privacy Control signal, your visit is not counted and nothing is stored.

Although the hash cannot be reversed, we treat it as personal data (pseudonymised data) and protect it accordingly.

  • We do not use cookies or other techniques to follow you around this website or others.
  • We do not sell, rent or share personal data with third parties for their own purposes.
  • We do not use the data for advertising, profiling or automated decisions (Article 22 GDPR).

The informational privacy notice shown when you arrive can be closed with the "Entendido" (Got it) button. So that it is not shown to you again, the website then saves a technical flag called sr_aviso_privacidad in your browser's local storage (localStorage). It is not a cookie: it is not sent to any server, it contains no identifier and it cannot be used to recognise you. You can delete it whenever you want from your browser settings (clear site data).
